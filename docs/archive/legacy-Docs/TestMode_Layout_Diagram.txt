## Detailed Coordinate Reference

### Actor Positions (Unreal Units)

| Actor | X | Y | Z | Description |
|-------|---|---|---|-------------|
| Floor Center | 0 | 0 | 0 | World origin, ground reference |
| Player Start | 0 | 0 | 100 | 100 units above floor |
| Spaceship Spawn | 500 | 0 | 200 | 500 units forward, 200 up |
| Directional Light | Any | Any | High | Angled -45° pitch |

### Distances Between Key Points

| From | To | Distance | Notes |
|------|----|---------:|-------|
| Player Start | Spaceship | ~539 units | Diagonal distance |
| Player Start | Floor | 100 units | Vertical drop |
| Spaceship | Floor | 200 units | Vertical clearance |
| Floor Center | Spaceship | ~536 units | Horizontal + vertical |

### Scale Reference

```
1 Unreal Unit ≈ 1 centimeter (default)

Therefore:
- Floor dimensions: ~1000m x 1000m (at scale 100,100,1)
- Player height: ~1m above floor
- Spaceship height: ~2m above floor
- Spaceship distance: ~5m forward from player
```
