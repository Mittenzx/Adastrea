## 🎮 Demo Experience (30 Minutes)

### Guided Flow
1. **Spawn** → Tutorial overlay (30 sec)
2. **Fly to Station 1** → Dock (1 min)
3. **Buy FoodRations** → Cheap at Agricultural (1 min)
4. **Fly to Station 2** → Sell for profit (2 min)
5. **Buy SteelAlloy** → Fly to Station 3 (2 min)
6. **Sell SteelAlloy** → Big profit (1 min)
7. **Upgrade Ship** → Larger cargo (1 min)
8. **Advanced Route** → Luxury goods, higher risk/reward (5 min)
9. **Save Game** → Quit → Reload → Continue (1 min)
10. **Free Play** → Explore remaining routes (15 min)

### Key Moments to Polish
- Docking: Visual ring + chime + UI open
- Trade: Profit pulse + cash sound + cargo update
- Upgrade: Ship visual change + capacity increase
- Save: Confirmation + seamless reload
