Adastrea — Modular Ship System

Size-class carcass + scaled add-on parts, exported per-component for UE 5.8 (X4 / Starfield / Space Engineers style)

Why modular (X4/Starfield/SE)

  • • Components are independent meshes, not one blob
  • • Each part has its own pivot + material slot
  • • Supports damage/break-off subsystems (X4)
  • • Parts snap/scaffold onto a shared scale (Starfield)

Size-class scaling

  • • small / medium / large define scale + carcass dims
  • • Add-ons scale via sc(sz) — engine/cargo/weapon fit any class
  • • One part library, many ships

Pipeline

  • • Blender headless bpy -> FBX per part
  • • 2K PBR D/N/R/M/AO/E textures
  • • Numeric QA: tri budget, degenerate, symmetry, UV
  • • 21 FBX total + 60 textures, UE-import-ready
